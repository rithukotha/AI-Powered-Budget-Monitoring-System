The AI-Powered Budget Monitoring System is a full-stack web application designed to simplify personal financial management through automation and intelligent analysis. The system enables users to securely register and log in, after which they can record their daily expenses either manually or by uploading receipt images. The uploaded receipts are processed using Optical Character Recognition (OCR), which extracts relevant information such as expense amount and description, reducing manual effort. The extracted and user-entered data is preprocessed and stored in an SQLite database for further analysis. A machine learning model based on the Naive Bayes algorithm is used to automatically categorize expenses into predefined categories such as food, travel, and utilities. In addition, a Linear Regression model analyzes historical expense data to predict future spending patterns, helping users plan their budgets effectively. The system also incorporates a rule-based module to generate financial insights, alerts, and a financial health score based on user spending behavior. All results are presented through an interactive dashboard that displays charts, summaries, and trends, enabling users to easily understand their financial status and make informed decisions. The system is implemented using Python and Flask for backend processing, HTML, CSS, and JavaScript for frontend development, SQLite for database management, and libraries such as scikit-learn and Tesseract OCR for machine learning and text extraction. The hardware requirements include a system with at least an Intel i3 processor, 4GB RAM, and sufficient storage, while the software requirements include Python 3.x, Flask framework, required libraries, and a web browser for execution. Overall, the project provides an efficient, automated, and user-friendly solution for expense tracking, improving accuracy, reducing manual workload, and enhancing financial awareness.
